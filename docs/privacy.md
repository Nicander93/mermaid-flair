# 隐私说明

Mermaid Flair 在宿主本地读取当前文档的 Mermaid 代码块，使用包内 Mermaid 渲染。插件没有遥测、外部渲染服务或 CDN 依赖。

Obsidian 渲染器在禁止联网的隔离 iframe 运行，VS Code／Cursor 使用宿主 Markdown 预览或可选独立 Webview，并遵循其 CSP。图表使用净化 SVG 和 Shadow DOM，导出剔除活动内容、外部资源引用及链接，PNG 从同一份 SVG 生成。

点击复制图像会将完整 PNG 写入本机剪贴板；复制选中文字则写入标签文本。只有用户触发复制才写入剪贴板。保存 PNG 或导出 SVG 才会生成用户文件。高级菜单中的源码定位只打开本机原文并选择对应行，不修改 Markdown。原生预览通过随机令牌关联原文，使用宿主 URI 回调或右键菜单命令定位，不启动外部服务。

插件保存默认主题、跟随宿主明暗及悬浮工具栏设置。自动配色在渲染时计算，无需把颜色写回文档，也不保存逐图的节点颜色。
