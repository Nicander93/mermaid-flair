## Mermaid Flair 0.5.2 — Public Preview

在 VS Code/Cursor 的普通 Markdown 预览与 Obsidian 阅读视图中美化 Mermaid。

- Whiteboard、Clean、Paper 三套主题，跟随宿主明暗和代码字体。
- 自动分组配色；暗色画布采用浅彩节点和清晰的连线。
- 放大、平移、要素选择、复制完整 PNG，以及 SVG 导出。
- 本地渲染，无需账号或外部渲染服务。

### 安装 / Install

- **VS Code / Cursor**：下载 `.vsix`，使用 **Install from VSIX…** 安装，然后重载窗口。
- **Obsidian**：解压 `mermaid-flair-obsidian-0.5.2.zip`，将其中的 `mermaid-flair` 目录复制到笔记库的 `.obsidian/plugins/` 下，启用插件并打开阅读视图。Live Preview 保持内置渲染。
- `main.js`、`manifest.json` 和 `styles.css` 也提供独立下载。`SHA256SUMS.txt` 包含所有安装附件的 SHA-256 校验值。

### 验证范围 / Validation

35 项自动测试；Obsidian 1.15.0 原生验证。VS Code/Cursor 本版的原生验收仍有记录在案的缺口；macOS/Linux 原生交互尚未完成验收。此版本为公开预览版，尚未上架插件商店。
