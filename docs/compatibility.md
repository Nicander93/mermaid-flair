# 兼容性

## 宿主

当前版本为 0.5.2，共享渲染器及主题通过 35 项自动回归。Obsidian 实际运行时 API 版本为 1.15.0，本版已通过原生阅读视图、复制图像、默认主题保存及实际明暗切换。本轮原生脚本直接记录运行时 API 版本，不依赖安装器版本或更新提示。

VS Code/Cursor 本轮通过预览集成的浏览器及构建包测试，未重跑原生交互。最近一次 Cursor 3.28.7 原生验证使用 0.5.0，同标签 Preview 通过键盘交互，隔离登录界面限制鼠标和剪贴板验收；VS Code 1.141.2 当次隔离启动没有创建工作台窗口，真实宿主交互尚待复验。详细范围见[测试记录](test-plan.md)。

| 宿主 | 接入方式 | 限制 |
| --- | --- | --- |
| VS Code / Cursor | 普通 Markdown Preview；另保留可选独立预览命令 | 剪贴板能力受宿主权限影响；失败时可用右键保存 PNG。 |
| Obsidian 桌面版 | Reading View 的 Mermaid 代码处理器 | Live Preview 保持内置渲染。 |

未进行移动端及 macOS/Linux 真实宿主验证。明暗配色和字体跟随各宿主公开设置。

## 图表

| 样本 | 结果 |
| --- | --- |
| Flowchart LR／TD、子图、树分支、共享依赖、长标签、中文 | 通过；完整 shell 样例覆盖三套主题的亮暗模式。 |
| Sequence OAuth2，含 alt、loop、note | 通过，参与者自动配色，沿用 Mermaid 布局。 |
| State、Class、ER、Gantt、Mindmap、Pie | 样例可渲染；自动结构分组仅用于流程图，其他图型按其支持的主题变量着色。 |
| 非法语法 | 显示简短提示和可展开诊断，其余图继续渲染。 |
| 依赖远程图片的图表 | 外部资源被拦截，无法布局时显示诊断。 |

手绘装饰覆盖可识别的流程图和时序图几何元素；其他图形保留官方 Mermaid 输出。升级 Mermaid 时需同步检查分组数据适配与 SVG 选择标记。

## 发布

GitHub Release 统一使用与插件版本一致的纯版本号 tag，同时提供 VSIX、Obsidian ZIP、独立插件文件及 SHA-256 校验值。CI 校验通过后发布为公开预览版；插件商店上架仍需单独提交。
